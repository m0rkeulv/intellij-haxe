### should-fix — src/main/java/com/intellij/plugins/haxe/model/evaluator/HaxeUntypedParameterInference.java:50
`bindingCache` is a `static` application-global map holding strong references to PSI (`HaxeParameter` keys, `ResultHolder` values containing PSI), but its only invalidation is `HaxeUntypedParameterInference.clearCaches()` called from `HaxeExpressionEvaluatorCacheChangeListener` — a per-PROJECT `projectListeners` registration (plugin.xml:735). Consequences: entries from all open projects share one map and any project's PSI change wipes them all (churn), and after the last Haxe project closes its PSI stays strongly referenced forever since no listener remains to clear it. The sibling caches this one is documented to clear alongside (`HaxeExpressionEvaluatorCacheService`, `HaxeCallExpressionEvaluatorCacheService`) are project services with the same listener plus `LowMemoryWatcher`. Make this a project-level service (or an instance map inside one of the existing cache services) so lifetime and invalidation match the rest of the evaluator caches.
